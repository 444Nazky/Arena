# Arena

A simple arcade game collection with fast-paced gameplay, easy controls, and score-based challenges.

## Gameplay

Players jump into quick arcade rounds with simple controls and fast action. The goal is to survive, score as high as possible, and handle increasing difficulty as the game progresses.

## Features

- Fast-paced arcade gameplay
- Simple and easy controls
- Score-based challenge system
- Increasing difficulty
- Casual pick-up-and-play experience

## Getting Started

1. Clone the repository.
2. Open the project in your browser or run it locally.
3. Start playing and try to beat your high score.
